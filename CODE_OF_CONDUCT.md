# Code of Conduct

ScolaOS is built for a broad education community. Project spaces must stay professional, constructive, and safe for contributors with different backgrounds and levels of experience.

## Expected behavior

- Discuss ideas and code on their technical merits.
- Give specific, actionable review feedback.
- Assume neither expertise nor incompetence from identity or background.
- Respect privacy and do not post real student/school data in issues, examples, screenshots, or test fixtures.
- Accept maintainer decisions on scope and architecture while using ADRs/issues to challenge decisions constructively.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, doxxing, sexualized attention, deliberate disruption, publication of private data, or public disclosure of an unremediated vulnerability are not acceptable.

## Enforcement

Maintainers may edit/remove content, close or lock discussions, reject contributions, or restrict participation when needed to protect the project and community. Serious safety or security matters should be reported privately to the repository owner.
